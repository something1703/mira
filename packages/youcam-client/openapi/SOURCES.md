## Notes for readers

- The bundles say `servers: https://yce-api-01.makeupar.com` and show no regional servers.
- A known bundling quirk: many `GET .../{task_id}` schemas show `data.results: null` with a `$ref` to `TaskStatusResponseBodySingleUrlResultsV2` hoisted to the wrong level. The intended shape is `data.results = { url }`. Check the per-feature "Inputs & Outputs" prose before trusting a generated client.
- Feature-specific error codes, such as `error_src_face_too_small` or `error_face_angle_upward`, appear only in each bundle's `info.description` "File Specs & Errors" table. They are not in the `data.error` enum, which is a generic `EngineErrorCode` list.
- Two pieces of information are not in any bundle. The JS Camera Kit docs are an included partial, rendered only on the HTML reference pages, for example https://docs.perfectcorp.com/reference/ai_skin_analysis. The webhook spec is at https://docs.perfectcorp.com/develop/webhook.
