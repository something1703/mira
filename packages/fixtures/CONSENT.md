# Consent register

Any recording whose result image shows a real person's face needs that person's written consent
before it is committed (docs/SECURITY_PRIVACY.md §5, AGENTS.md §11). One row per person.

| Person (initials) | Recordings (folder / name) | Consent given (date) | Where the consent is kept | Scope | Withdrawn |
| ----------------- | -------------------------- | -------------------- | ------------------------- | ----- | --------- |
| _none yet_        |                            |                      |                           |       |           |

Rules:

- No recording of a face is committed without a row here.
- A person can withdraw. Delete their recordings and fill the last column.
- Recordings of AI-generated or product images need no row, but say so in the fixture's name.
- Never write a person's name, contact details or the consent document itself in this file.
