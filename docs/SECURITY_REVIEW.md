# Security review

A review of the code as built, against `docs/SECURITY_PRIVACY.md`. It was done by reading the code and running its tests, by the people who wrote it. It is **not** a penetration test, nothing here has run against a live deployment, and Terraform and Firestore rules are written but not applied. Date: 2026-11-01.

## Findings fixed in this review

| #   | Finding                                                                                                                                                  | Fix                                                                                                                                                                         |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1  | `/api/proof/claim` and `/api/look/garments/extract` make MIRA fetch somebody else's website for a signed-in person with no limit on how often.            | Both now use the per-person `RateLimit` the shade-range route already had (12 an hour), answering 429 `too_many_reads`.                                                       |
| S2  | `mira-mcp` checked the bearer token inside the handler, after the framework had read and parsed the whole body, so a caller with no token could make it buffer up to the global limit. | The check moved to an `onRequest` hook, which runs before the body is read. The route has an explicit 12 MB body limit (two 5.6 MB pictures as base64) and a test covers both. |
| S3  | `.ics` reminders put the product name in a `SUMMARY` line after replacing only commas, semicolons and `\n`. A `\r`, other control character or backslash could add a line to the file. | All control characters and backslashes are replaced with a space. A unit test tries to inject an `ATTENDEE` line.                                                            |

## Checked, no change needed

| Rule in SECURITY_PRIVACY.md                    | What was checked                                                                                                                                                                                                                                                                         |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| §1 No image reaches a language model           | The agent's providers take text and tool results only. The panel never holds a photo (D38 (5)). Page extraction sends page text, never a picture.                                                                                                                                       |
| §1 Twin and brand rows are numbers only        | Brand rows hold shade, concern, delta, band and ISO week; ids are hashes; rows are removed on opt-out and on profile delete; demand rows are never written from synthetic twins (tests in `apps/workflows/tests/brand.test.ts`).                                                          |
| §2 Secrets                                     | A scan of tracked files found no key patterns. The only tracked env file is `.env.example`; `.gitignore` has `.env*`. The YouCam key a person pasted into chat is only in the ignored `.env.local`, and they were told to rotate it.                                                    |
| §3 MCP bearer and caps                         | No token, wrong token and an empty token list all answer 401. Caps are per token per UTC day. They are held in memory, so the service must stay at one instance (recorded as a limit in D41).                                                                                              |
| §4 URL fetch                                   | `safe-fetch.ts`: https only, public addresses only (checked again at connect time), redirects followed by hand and re-checked, size and time limits. Pages are data: output is schema-validated and the 55 agent evals include injection and confirmation-bypass.                          |
| §6 Logging                                     | Logs carry trace ids, route, status and timing. No handler logs a body, an image or a URL of one.                                                                                                                                                                                       |
| Dev routes                                     | `/internal/dev/*` (session cap, twin and proof seeds) exist only in the mock-only block and are not registered in live mode.                                                                                                                                                              |
| Brand console                                  | Every brand workflow answers 403 `console_closed` outside mock mode, because brand sign-in is not built. Nothing about a brand is reachable in a live deployment.                                                                                                                        |

## Open: not done, and what that means

| #   | Gap                                                                                                                                              | Consequence until closed                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| O1  | Live adapters (Firestore, Cloud Tasks, Pub/Sub, GCS) are not built, so Firestore security rules and the one-day storage lifecycle are untested.   | The "images are deleted" claim is tested against the file-backed mock only. Not claimed for a live deployment.    |
| O2  | Terraform is written but has not been validated or applied.                                                                                       | No deploy until CI validates it and the cost is approved.                                                         |
| O3  | Brand sign-in is not built (planned D41).                                                                                                         | The brand console is closed in live mode.                                                                         |
| O4  | Agent plans, the unit ledger of `mira-mcp` and rate limiters are in process memory.                                                               | These services must run as one instance; a restart forgets a plan, a day's MCP spend and the request counts.     |
| O5  | No scan of dependencies for known vulnerabilities beyond what CI runs, and no test from outside the network.                                       | Run `pnpm audit` and an external check as part of the deploy.                                                    |
| O6  | The pasted YouCam key has not been confirmed rotated.                                                                                             | The user should rotate it before any live run.                                                                    |
