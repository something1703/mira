| D20 | 2026-11-01 | Dark `--mira-accent-wash` is 0.10 alpha (was 0.14); the Ring's reading tick has a `--mira-raised` casing where it crosses the mirror | The contrast test (`packages/ui/tests/contrast.test.ts`) found accent text on the dark wash at 4.37:1 (AA needs 4.5) and the accent tick on the mat at 1.66:1 (non-text needs 3). 0.10 matches the light theme; `--mira-raised` against the mat is above 3:1 in both themes and the accent clears 3:1 against it | Lighter dark accent (breaks the one-accent identity); ink text on the wash (loses the verified colour cue) |
| D18 | 2026-11-01 | Keep six scale-to-zero Cloud Run services; do **not** merge them into one instance | Cloud Run bills an instance's whole allocated CPU and memory for as long as any request is active, so one instance holding six services bills all of them together, and a warm one idles at their summed allocation (about $45/month against about $13 for a warm web app alone). Scale-to-zero services bill only the one that is working, and idle costs nothing | One multi-container service with sidecars; a VM running everything (a fixed $13–27/month whatever the traffic) |
| D17 | 2026-11-01 | Gemini 3 Flash (`gemini-3-flash-preview`) for both the main loop and extraction, gated by the agent evals | $0.50 in / $3 out per million tokens, a third of Gemini 3.5 Flash ($1.50 / $9), about 0.6¢ per assistant turn. Output is schema-validated with a retry and templated fallback, and the model never types numbers, so a faster model does not weaken the trust guarantees. `pnpm eval:agent` must stay at or above 95%; if it drops, set `MIRA_MODEL_MAIN=gemini-3.5-flash` (one env var). It is a preview ID, so re-check availability before the final demo | Claude Sonnet 5.5 on Vertex ($2 / $10, about 4× the cost) |
| D16 | 2026-11-01 | Build Twin computes a **same-session** variation estimate (s_w from the repeat captures); day-to-day variation (s_d) exists only after 3 sessions on different days | ENGINES §8 needs n ≥ 3 sessions for s_d; calling a one-session number a "noise floor" would overstate it | Label the first session's spread as the noise floor |
